# Gap to Plan

Measure the gap between current state and a stated aim, then turn the delta into an executable multi-plan hierarchy.

## Process

1. **Capture the aim** clearly (the target state).
2. **Inventory current state** (code, artifacts, capabilities, evidence).
3. **Compute the delta** — what is missing, broken, or insufficient.
4. **Distill into assemblable parts** — concrete pieces that can be planned and built.
5. **Deconstruct into hierarchy**:
   - Always produce tasks.
   - Add phases / stages / plans only when the size warrants it.
   - Max ~10 phases per plan (prefer ≤8); split into multiple plans when larger.
6. Write durable plan artifacts that later implement / gauntlet / LFG steps can follow.

## Rules

- Be honest about the size of the gap.
- Prefer fewer, clearer plans over deep nesting for its own sake.
- Every leaf should be actionable.
- Link back to evidence from the current-state inventory.

## Output

Structured plans (markdown or equivalent) under a clear location, ready for sequencing or fan-out.
