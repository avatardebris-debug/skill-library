# Readiness tags (owned by /dedede)

| Tag | Use when | Later action |
|-----|----------|--------------|
| **replicate** | Clear process I/O; evaluable or automatable steps | Fan-out /lfg candidate |
| **defer** | Possible later; out of scope/cost now | Skip fan-out |
| **human_only** | Taste, original authorship, legal person, live authority | Human queue / never auto-own |
| **unknown** | Need research or more depth | Research or expand; not LFG yet |

## DE owns vs build owns

| Claim | Owner |
|-------|--------|
| Should not try / human must own | **dedede** |
| Practical to attempt as software | **dedede** (replicate) |
| Reached human/near-human bar | **build** (lfg/harsh critic) |
| Plateau / can't improve easily | **build** after attempts |
| Runtime skip of missing modules | **orchestrator** |

## Heuristics

- Original story/IP direction -> human_only  
- Sprite export pipeline with checklist -> often replicate  
- "Be creative on brand voice" without rubric -> human_only or unknown  
- SEO technical crawl with toolable checks -> replicate candidate  
- CEO fundraising relationships -> human_only  

Do not invent metrics to force replicate.
