# Depth levels

| L | Name | Expand? |
|---|------|---------|
| 0 | Entity | Always once |
| 1 | Dept / workstream | Breadth pass all (or focus) |
| 2 | Role | Depth if duties differ |
| 3 | Process | Preferred leaf grain |
| 4 | Steps / tools / artifacts | If changes readiness or I/O |
| 5 | Metrics | Only if real |

## Multi-pass

1. Breadth: L0-L1  
2. Depth: L2-L4 on focus  
3. Research: unknown/hot  
4. Readiness: all leaves  

Stop expanding a branch when readiness is stable and further split adds no new leaf type.
