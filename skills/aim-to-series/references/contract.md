# aim-to-series contract

## One-liner

```text
large aim → [thin research] → notes/series/<slug>/{SERIES,ROADMAP,leaves}
  → STOP (human skim)
  → (later) /series-loop or /overnight-series
```

## Hard rules

1. Bootstrap only; never unattended loop from this skill.
2. Leaves must be gap_to_plan-sized; no series-root mega-leaf.
3. Empty aim → refuse; do not invent product direction.
4. Overnight `no_leaf` may *recommend* this skill; it must not auto-run expand
   without an aim string from the operator or a prior approved charter.

## Hand-off to loops

Human picks series-loop or overnight-series after skim. Soft QC stays in
after-series / overnight playlist — not here.
