# admit-fuel rubric (research fuel)

Axes 1–5: usefulness, cost_efficiency, risk_safety, unify, evidence_fit, coherence.

## Verdict floors

- **REJECT** if hard phrase (auto-train/LFG, invent field_proven, outer RSI unattended) or diversion without thin map  
- **REJECT** souvenir: no surface map + low usefulness  
- **MODIFY** if strong surface map + safe risk + moderate usefulness  
- **ADMIT** if high usefulness + high cost_efficiency + high risk_safety + high unify + high coherence  
- **DEFER** otherwise when risk ok (default for unmapped papers)

DEFER is success. Cap shippable (ADMIT+MODIFY) hint at 3 for suggest.
