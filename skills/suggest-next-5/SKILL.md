# Suggest Next 5

Produce a focused shortlist of the 5 highest-ROI next projects, each with a concrete path through software-factory (or related skills).

## Process

1. Inventory current workspace state, residual gaps, recent receipts, and open aims.
2. Score candidate projects on leverage, readiness, and strategic fit.
3. Select the top 5.
4. For each, write a ready-to-paste aim line and the recommended skill sequence (e.g. /lfg, /software-factory, /gap-to-plan first, etc.).

## Output

Numbered list of 5, each containing:
- Short title
- Why now (1–2 sentences)
- Exact command / skill path to run it
